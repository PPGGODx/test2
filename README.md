# PlayZongX — แอปฟังเพลง Hybrid (YouTube Music + โฟลเดอร์ Zong ในเครื่อง + Google Drive Sync)

แอปพลิเคชันฟังเพลงบน Android ดีไซน์ **Spicetify Crimson Glass** แบบ **Offline-First**
- **ออนไลน์:** ค้นหาและสตรีมเสียงคุณภาพสูงจาก YouTube Music (InnerTube API)
- **บันทึกเพลงลงโฟลเดอร์ `Zong` ในเครื่อง:**
  - ทันทีที่ติดตั้งและเปิดแอป ระบบจะสร้างโฟลเดอร์ **`Music/Zong`** (`/storage/emulated/0/Music/Zong`) บนตัวเครื่องโดยอัตโนมัติ
  - ทุกเพลงที่ดาวน์โหลดจะถูกฝัง **ปกเพลง (`covr`) + ชื่อเพลง (`©nam`) + ศิลปิน (`©ART`)** ลงในไฟล์ `.m4a` (`ชื่อเพลง - ศิลปิน.m4a`) โดยตรง
  - ย้ายไฟล์ไปเครื่องอื่น เปิดในแอปเล่นเพลงอื่น หรือติดตั้งแอปใหม่ เพลงและรูปปกในโฟลเดอร์ `Zong` จะถูกสแกนกลับมาแสดงครบถ้วน
- **เชื่อมต่อ Google Drive โดยตรง (ไม่ต้องตั้งค่า Google Cloud):** เลือกโฟลเดอร์ Google Drive เพื่อซิงก์เพลย์ลิสต์และสำรองไฟล์เพลงข้ามเครื่องได้ทันที

## วิธี Build ไฟล์ `.apk` บน GitHub (พร้อมแตกไฟล์อัปโหลดได้ทันที)

1. **แตกไฟล์ `.zip` นี้** (`PlayZongX-Android-GitHub-v6.zip`) ออกมาเป็นโฟลเดอร์โปรเจกต์
2. **สร้าง Repository ใหม่บน GitHub** (ตั้งชื่อเช่น `PlayZongX` เป็น Public หรือ Private ก็ได้)
3. **อัปโหลดไฟล์ทั้งหมดในโปรเจกต์ขึ้น Repository** (รวมโฟลเดอร์ `.github/workflows/build-apk.yml` และไฟล์ `app/hybrid-music.jks`)
4. ไปที่แท็บ **Actions** บนหน้า GitHub Repository ของคุณ
5. เลือก Workflow ชื่อ **Build PlayZongX APK** (ระบบจะเริ่มรันอัตโนมัติทันทีที่ Push โค้ด หรือกดปุ่ม **Run workflow** ได้เลย)
6. รอประมาณ 3–5 นาที จนขึ้นเครื่องหมายถูกสีเขียว ✅
7. คลิกเข้าไปในรอบที่รันเสร็จ เลื่อนลงมาด้านล่างตรงหัวข้อ **Artifacts** แล้วคลิกดาวน์โหลด **`PlayZongX-Debug-APK`**
8. แตกไฟล์ `.zip` จะได้ไฟล์ **`app-debug.apk`** นำไปติดตั้งบนมือถือ Android ได้ทันที
